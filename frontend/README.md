# TossWatch frontend

React + TypeScript + Vite. See the repo root [README](../README.md) and
[docs/PLANNING.md](../docs/PLANNING.md) for the full project context.

## Dev

```bash
npm install
npm run dev
```

The dev server proxies `/api/*` to the backend at `http://localhost:8080`
(see `vite.config.ts`), so make sure the backend is running too.
